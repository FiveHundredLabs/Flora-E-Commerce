# Frontend foundation

React 19 + Vite + strict TypeScript foundation for FE-0101. From the workspace root run `npm ci`, `npm run dev`, and the validation commands in `docs/TESTING.md`. The home page shows catalog unavailability; unknown routes offer recovery. No backend calls are enabled. The `.env.example` is illustrative, not an approved backend URL. Playwright requires an installed Chromium browser (`npx playwright install chromium`).
