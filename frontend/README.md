# Frontend foundation

React 19 + Vite + strict TypeScript foundation. Use Node 22 (at least 22.12; see `.nvmrc`) and npm 11. If your environment ships npm 9, use `npx npm@11 ci` for installation. From the workspace root run `npm ci`, `npm run dev`, and the validation commands in `docs/TESTING.md`. The home page links to labeled sample shops/products; unknown routes offer recovery. No backend calls are enabled. The `.env.example` is illustrative, not an approved backend URL.

Playwright tests build and serve the production bundle. Install Chromium with `npm exec -w frontend playwright install chromium`, then run `npm run test:e2e`. To use an already installed Google Chrome instead, run `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`. The smoke suite checks navigation, keyboard skip focus, overflow and axe accessibility at mobile/tablet/desktop widths. Automated accessibility checks do not replace screen-reader review.

`app/` composes routing, error boundary, Query and Redux cart providers; `pages/` composes public feature interfaces; `shared/` contains neutral primitives; `test/` installs React Testing Library and MSW lifecycle hooks. Test requests require explicit MSW fixtures; unhandled network requests fail. Redux now owns cross-route sample cart references/quantities only. Query owns catalog/order/feedback entities.

`features/discovery/` implements sample shops/products and URL filters. Product detail now includes an injected Add to sample cart control. `features/commerce/` supplies `/cart`, `/checkout?store=…`, `/account/orders` and sample order details/feedback. Add products through client navigation to retain the in-memory demo state; full reload resets it. No real prices, payment requests or delivery bookings exist. See the workspace's `docs/FE-0301_CUSTOMER_DISCOVERY.md` and `docs/FE-0401_CUSTOMER_COMMERCE.md` for contracts and limits.
