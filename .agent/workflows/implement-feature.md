# Feature implementation workflow
1. Read project rules and task.
2. Trace client requirement to UI behavior.
3. Identify unknown API/business behavior; stop or use clearly labeled mock adapters.
4. Propose changed files and test cases.
5. Implement minimal vertical slice.
6. Add unit/component/E2E tests appropriate to behavior.
7. Run checks and record actual results.
8. Submit change summary, risks and follow-ups.
